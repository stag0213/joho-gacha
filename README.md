# 確率シミュレーション教材パック(高校「情報Ⅰ」)
## 乱数によるくじ引き実験を通して、乱数と擬似乱数・シミュレーション(モンテカルロ法)・大数の法則を学ぶための教材セットです。確率と引く回数を指定してシミュレーションを実行できます。



### 動作環境・使い方
index.html をブラウザ(Chrome / Edge / Firefox / Safari の最近のバージョン)で開くだけです。

インストール・サーバー・ネット接続は不要(オフライン授業 OK)。

ページを開くと、初期設定(サイコロ 1/6・1,000回)で自動的に1回デモ実行します。

### 配布方法: ファイルをそのまま生徒端末に配布・共有しても動作します。
### アプリの機能
区分	機能

① 設定	当たりの確率を分数(1/6 など)または % で指定。プリセット: コインの表 1/2 / サイコロの6 1/6 / くじ 1/10 / レアくじ 1/100

① 設定	引く回数を 10〜1,000,000 回で指定(10 / 100 / 1,000 / 1万 / 10万 のボタン付き)

② 結果	引いた回数・当たり・はずれ・実測確率(相対度数)と理論確率との差(ポイント)を表示

② 結果	「引いた結果の記録」— 当たり(朱色)・はずれ(グレー)の札を最新160回分表示

② 結果	実測確率の推移グラフ(横軸:対数スケール)— 試行回数を増やすと理論確率の破線に収束する様子を確認(大数の法則)

③ 発展	同じ実験を最大 2,000 セットくり返して実測確率のヒストグラムを描画。1セットの回数が多いほど山が細くなることを確認

その他	学習ポイント(乱数と擬似乱数 / 大数の法則 / モンテカルロ法)と授業手順の解説をアプリ内に掲載

### 実行性能の目安

10万回: 約4秒(アニメーション付き)

100万回: 約10〜15秒(グラフ更新間隔が自動的に粗くなります)

くり返し実験: 総試行数が多すぎる場合はエラーで中止するので、回数を減らしてください。

### 授業での進め方(50分想定)

導入 — スライド3枚目の発問「6回引けば必ず1回当たる?」で直感を引き出す。

基礎 — 乱数と擬似乱数、シミュレーション(モンテカルロ法)の説明。

操作説明 — アプリ画面(設定 → 実行 → 結果)を紹介。押す場所は3つだけ。

実験① — 引く回数を 10 → 100 → 1,000 → 10万回 と増やして実行し、実測確率が理論確率に近づくことを確認(大数の法則)。

実験② — くり返し実験のヒストグラムで、「1セットの回数が多いほどばらつき(山の広がり)が小さくなる」ことを確認。

まとめ — 確認クイズ2問+振り返り。次時はモンテカルロ法の活用へ。

### 免責・ライセンス

乱数にはブラウザ標準の Math.random()(擬似乱数)を使用しています。

授業内での利用・改変・生徒への配布は自由です。

本教材は高校「情報Ⅰ」の学習用であり、正確な乱数性が求められる研究用途にはそのまま使えません。
